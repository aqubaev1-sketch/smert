# smert

Қазақ тіліндегі «Нейрондық желілер және генеративті ЖИ» тақырыбына арналған көп ойыншылы викторина.

## Мүмкіндіктер

- 4 таңбалы бөлме коды
- 10 ойыншыға дейін
- Аты мен 5 персонаждың бірін таңдау
- 20 сұрақ
- Жүргізуші және ойыншы экрандары
- Ұпай, өмір және финалдық рейтинг

## Іске қосу

Node.js 18 немесе одан жаңа нұсқасы қажет.

```bash
node server.mjs
```

Компьютерде `http://127.0.0.1:8765/` мекенжайын ашыңыз. Бір Wi-Fi желісіндегі телефондар компьютердің жергілікті IP-мекенжайы арқылы қосыла алады.
